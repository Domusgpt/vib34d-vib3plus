# VIB34D Visualizer Skill

**Create interactive 4D visualizations with the VIB34D SDK**

---

## What This Skill Does

This skill helps you create 3D/4D visualizations using the VIB34D XR Quaternion SDK. I can:

- Generate complete Flutter apps with visualizations
- Create custom geometries (tesseracts, spheres, grids, custom)
- Set up input methods (mouse, touch, keyboard, gamepad)
- Configure colors, animations, and effects
- Optimize for web, mobile, or desktop
- Debug quaternion math and rotations
- Export code ready to run

---

## Quick Commands

- `vib34d create <type>` - Create a new visualization
- `vib34d add input <method>` - Add input adapter
- `vib34d add geometry <shape>` - Add geometry renderer
- `vib34d optimize` - Suggest performance improvements
- `vib34d explain` - Explain quaternion concepts
- `vib34d debug` - Debug quaternion issues
